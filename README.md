# Портфолио juzo44

Персональное портфолио разработчика и веб-дизайнера.

## Сайт

Опубликовано на GitHub Pages: **https://juzo44.github.io/portfolio/**

## Страницы

- Главная — о себе, услуги, избранные проекты
- Проекты — работы с фильтрами
- Обо мне
- Контакты
- Резюме (есть печать в PDF)

## Проекты

- **GRID — игровая экосистема Minecraft** — десктоп-лаунчер на Electron, мод главного меню для NeoForge, серверная часть на Node.js, официальный сайт проекта
- **Flow — доска задач** — таск-менеджер в браузере (https://flow-juzo.netlify.app)

## Технологии

JavaScript, Node.js, Electron, Java, NeoForge, HTML/CSS, Figma, git.

## Локальный запуск

Просто откройте `index.html` в браузере. Дополнительных зависимостей и сборки не требуется.

## Структура

```
assets/        стили, скрипты, изображения
projects/      страницы отдельных проектов
index.html     главная страница
```
